# Bakin

Tu biblioteca de fotos y música, en tu PC (Windows 10 y 11).

**Descargar:** https://bladeholy.github.io/bakin-releases/

Este repositorio solo publica los instaladores firmados y el feed de
actualizaciones (`latest.json`); el código es privado. La página de descarga
está en `docs/` y usa [glass-midas](https://www.npmjs.com/package/@glass-midas/components) (MIT).
